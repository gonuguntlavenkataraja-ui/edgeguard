# Adaptive Edge Kernels for Face-Aware Threat Propagation
in Surveillance Systems

## Project Overview
Privacy-preserving edge-based surveillance system using
Raspberry Pi, computer vision and local face recognition.

## My Contribution
Frontend Development

- Designed surveillance dashboard
- Developed camera management interface
- Developed alerts interface
- Developed live-stream interface
- Developed profile and settings interfaces
- Integrated frontend API endpoints
- Designed responsive user interface

## Technologies
HTML
CSS
JavaScript

## Project Architecture
Camera → Raspberry Pi → Edge Processing → Face Detection
→ Face Recognition → Threat Logic → Alert → Frontend

Final Year Project – Team of 5
